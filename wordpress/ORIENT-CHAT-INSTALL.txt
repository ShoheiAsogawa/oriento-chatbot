オリにゃんを公式サイトへ入れる手順（テーマは触らない）

この方法はカスタムテーマ original2 を1行も編集しません。
おかしくなったら「プラグインを停止」するだけで元に戻ります。


やらないこと
- functions.php を開かない
- footer.php を開かない
- テーマの CSS / JS を編集しない
- 子テーマを作らない（今のサイトは子テーマではない）


準備
1. WordPress 管理画面にログインできること
2. 「プラグインを追加できる」権限があること（管理者）
3. 可能なら作業前にサーバーまたはプラグインのバックアップを取る
   （このプラグインはDBを書き換えません。止まれば表示が消えるだけです）


手順A：管理画面からZIPを上げる（いちばん簡単）

1. このリポジトリの wordpress/orient-orinyan-chat.zip をパソコンに保存する
2. WordPress 管理画面を開く
3. 左メニュー「プラグイン」→「新規追加」
4. 上の「プラグインのアップロード」をクリック
5. 「ファイルを選択」で orient-orinyan-chat.zip を選ぶ
6. 「今すぐインストール」→ 成功したら「プラグインを有効化」
7. 左メニュー「プラグイン」に「オリにゃんチャット」と出ていれば成功


手順B：FTP / ファイルマネージャでフォルダを置く

1. wordpress/orient-orinyan-chat フォルダごと上げる
2. 置き場所は必ずここ（テーマではない）
     /wp-content/plugins/orient-orinyan-chat/orient-orinyan-chat.php
3. 管理画面「プラグイン」を開き、「オリにゃんチャット」を有効化


入れたあとの確認
1. シークレットウィンドウで https://orijyu.com/ を開く
2. PC：右下に「おりにゃんに相談にゃ！」が出る
3. スマホ幅（または実機）：
   - 下のオレンジ「電話でお問い合わせ」はそのまま
   - オリにゃんはそのバーの上にいる（バーを隠さない）
4. オリにゃんを押してチャットが開く
5. トップ以外（物件詳細など）でも右下に出る


戻し方（10秒）
1. 管理画面「プラグイン」
2. 「オリにゃんチャット」の「停止」
3. サイトからオリにゃんだけ消える。テーマも電話バーも元どおり

完全に消すなら、停止したあと「削除」。
フォルダを上げた場合は
  /wp-content/plugins/orient-orinyan-chat
を消してもよい。


うまく出ないとき
- キャッシュ / 最適化プラグインを使っている：一度キャッシュ削除
- プラグインが「停止」のまま：有効化を確認
- 管理画面には出てフロントに出ない：別ウィンドウでログアウトして見る
- 電話バーと重なる：このリポジトリのウィジェット更新が本番に出たあと、
  自動で上にずれます。出る前でもプラグイン内の予備CSSで68px上げています


テーマへ直接書く方法は使わないでください。
wordpress/orient-chat.php は予備であり、functions.php への require は不要です。
