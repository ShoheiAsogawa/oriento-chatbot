本書は、株式会社オリエントホールディングス（以下「当社」）が提供するAIチャットボット「オリにゃんに相談」（以下「本チャット」）における、個人情報等の取扱いと免責事項を定めるものです。当社ウェブサイトの[個人情報保護方針](https://orijyu.com/policy.html)を補足し、本チャットに固有の取扱いを説明します。本書に定めのない事項には、当社の個人情報保護方針が適用されます。

ご利用前に必ずご確認ください。

- 本チャットの回答は一般的な案内です。契約、申込み、購入その他の重要な判断は、必ず当社担当者と正式資料で確認してください。
- マイナンバー、本人確認書類番号、口座・カード情報、パスワード、健康情報その他の要配慮個人情報や秘密情報を入力しないでください。
- 会話の入力内容と回答内容は、品質管理、監査、セキュリティおよびサービス改善のため記録されます。画面下部の案内および本書が、その記録に関する表示です。

# 1. 適用範囲と同意

本書は、本チャットの利用者（以下「利用者」）と当社との間で、本チャットの利用に関して適用されます。

- 本チャットを開き、メッセージを送信した時点で、画面上の記録案内および本書を確認のうえ、会話の記録に同意したものとして取り扱います。記録を希望しない場合は、本チャットを利用しないでください。
- 氏名・電話番号その他の連絡先の入力は任意です。注文住宅などの案内で連絡先を送信した場合は、そのご相談への対応および担当者からの連絡のために利用します。送信しない場合でも、公式LINEやお問い合わせフォームから相談できます。
- 本チャットの画面には、現時点でメールマガジン等の一般的な宣伝配信専用フォームはありません。連絡先の送信は、当該相談の対応を目的とします。

# 2. 取得する情報

当社は、本チャットの提供に伴い、次の情報を取得または生成します。

- 会話情報: 利用者が入力した文章、AIの回答、回答拒否等の判定、参照した公開資料、送受信日時。メールアドレスや電話番号の一般的な表記は、会話記録およびAI送信の前にマスキングします。
- セッション・技術情報: 本チャットを開いたページのURL、ブラウザ等の情報、ボット対策の確認結果、エラーおよび利用状況の記録、IPアドレスとブラウザ情報等から生成した復元できない仮名化識別子。
- 物件閲覧情報: 本チャット経由で公式の物件ページを開いた場合の、日本時間の日付、物件URL、仮名化識別子。個人の氏名や連絡先は含みません。
- 注文住宅の相談情報: 土地の有無・所在地・広さ、希望エリア、家族構成、間取り、予算、時期、こだわり等のヒアリング内容。利用者が任意で入力した氏名および電話番号。
- 顧客連絡先: 上記の連絡先を登録した場合の氏名、電話番号、同意日時（送信日時）、対応状況。メールアドレスを受け付ける経路がある場合は、そのアドレスも含みます。
- 監査情報: 管理者による閲覧、出力、設定変更、削除等の操作履歴、および記録の改ざん検知に必要な情報。個人情報そのものは含めません。

当社は、本チャット上で本人確認書類、金融口座、クレジットカード、パスワード等の入力を求めません。これらの情報は入力しないでください。評価ボタン等の任意フィードバックは、現時点では取得していません。

# 3. 利用目的

取得した情報は、次の目的で利用します。

- 利用者の質問に対する回答、関連情報の提示、公式LINEおよびお問い合わせフォーム等の有人窓口への案内
- 回答品質の確認、誤回答・未回答の分析、ナレッジおよび応答ルールの改善
- 不正アクセス、スパム、濫用、セキュリティ事故および障害の検知・防止・調査
- 会話・管理操作の監査、トラブル対応、法令・契約上の義務の履行
- 個人を識別しない統計としての利用状況の集計・分析（日次の相談件数、時間帯、物件ページの閲覧数など）
- 連絡先の送信がある場合の、当該相談（物件・家づくり・リフォーム等）に関する担当者からの連絡、社内共有および顧客対応

# 4. マスキング、暗号化および安全管理

チャット本文に含まれる一般的な形式のメールアドレスと電話番号は、会話記録およびAI送信の前に自動的にマスキングします。ただし、表記ゆれ、文脈、画像その他の事情により、すべての個人情報を完全に検出できることを保証するものではありません。不要な個人情報は入力しないでください。

注文住宅の相談で送信された氏名、電話番号およびヒアリング内容は、会話本文とは分離し、暗号化して保存します。検索・重複確認のため、復元できないハッシュ値および電話番号の末尾4桁を別途保持することがあります。会話本文には氏名・電話番号を残しません。

担当者への通知は、暗号化して保存した相談内容を復号したうえで、社内の担当者へ電子メールで送ります。通知メールおよびキューには、必要最小限の相談内容のみを含めます。

管理画面は認証とアクセス制御で保護し、管理操作を監査記録へ保存します。当社は、アクセス制限、暗号化、改ざん検知、バックアップ、レート制限その他の合理的な安全管理措置を講じます。ただし、インターネット上の通信・保存について絶対的な安全性を保証するものではありません。

# 7. 保存期間と削除

標準の保存期間は次のとおりです。管理画面の設定で短縮する場合があります。

- 会話情報: 当該会話の最終更新日から365日
- 注文住宅の相談記録: 紐づく会話の削除に伴い削除します。連絡先の顧客情報は次項に従います
- 顧客連絡先: 最終更新日から1095日
- 物件閲覧情報: 180日
- 個人を識別しない日次の利用件数: 90日

法令・契約上の義務、紛争対応、セキュリティ調査その他正当な必要がある場合は、必要な範囲で保存期間を延長することがあります。保存期間の経過後、対象情報は順次削除または匿名化します。バックアップ、配信キャッシュまたは監査記録には、技術上合理的な期間残存する場合があります。削除の事実や監査台帳の整合性を示すため、個人情報を含まない限定的な記録を保持することがあります。
