# プライバシー・セキュリティ

- チャット画面下部に「会話は品質管理のため記録されます」とプライバシーポリシー・免責事項へのリンクを表示する。
- 質問の前に性別（男性・女性・そのほか）と年代（10代〜60代以上）を選択してもらい、相談統計として会話単位で保存する。氏名には紐づけない。
- 会話記録は、性別と年代の選択をもって運用上の同意とする。氏名・電話番号・住所の入力は任意で、当該相談への担当者連絡に限って利用する。
- 資料請求・電話相談・見学予約・注文住宅の連絡先とヒアリング内容は会話本文と分離し、暗号化して保存する。連絡先は会話生成APIへ渡さない。
- メール、電話番号はモデル送信前にマスクする。
- 顧客情報は D1 に AES-256-GCM でフィールド暗号化し、検索用ハッシュと末尾4文字だけを別保持する。
- 担当者通知は復号した相談内容を Resend 経由で社内メールへ送る。
- 管理画面は管理者IDとパスワードのセッションで保護する。
- AI Gateway の本文ログは無効、アプリ独自監査ログは Cloudflare 内だけに保存する。
- 監査ログは月次台帳内で前イベントハッシュを含み、管理画面の再計算検証で削除・改変を検知できる。Durable Object内の永続OutboxによりQueue送信失敗も再試行する。
- 顧客CSVと会話CSVは認証済み管理者だけが取得でき、出力操作自体も監査イベントへ記録する。会話CSVはPIIマスク後の本文だけを含む。
- 標準保持期間は会話 365 日、顧客情報 1095 日、物件閲覧 180 日、日次利用件数 90 日。契約・法令・社内規程に合わせて設定画面で会話と顧客の期間を短縮可能にする。
- 削除要求は顧客 ID 単位で会話との関連を切り、暗号化 PII を消去し、監査台帳には削除実施の事実だけを残す。
