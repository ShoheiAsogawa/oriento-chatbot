# プライバシー・セキュリティ

- 会話開始時に「品質管理のため記録」を表示する。
- 質問の前に性別（男・女・そのほか）と年代（10代〜60代以上）を選択してもらい、相談統計として会話単位で保存する。氏名には紐づけない。
- 営業連絡へ転用する顧客情報は別の明示同意を必須にする。
- ウィジェットの連絡希望フォームは同意を既定でオフにし、メールまたは電話番号と明示同意が揃った場合だけ顧客DBへ登録する。連絡先は会話生成APIへ渡さない。
- メール、電話番号はモデル送信前にマスクする。
- 顧客情報は D1 に AES-256-GCM でフィールド暗号化し、検索用ハッシュと末尾4文字だけを別保持する。
- 管理画面は Access JWT と許可メールの二重確認を行う。
- AI Gateway の本文ログは無効、アプリ独自監査ログは Cloudflare 内だけに保存する。
- 監査ログは月次台帳内で前イベントハッシュを含み、管理画面の再計算検証で削除・改変を検知できる。Durable Object内の永続OutboxによりQueue送信失敗も再試行する。
- 顧客CSVと会話CSVはAccess認証済み管理者だけが取得でき、出力操作自体も監査イベントへ記録する。会話CSVはPIIマスク後の本文だけを含む。
- 標準保持期間は会話 365 日、顧客情報 1095 日。契約・法令・社内規程に合わせて設定画面で短縮可能にする。
- 削除要求は顧客 ID 単位で会話との関連を切り、暗号化 PII を消去し、監査台帳には削除実施の事実だけを残す。
